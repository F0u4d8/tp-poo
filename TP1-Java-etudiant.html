Installer Java (JDK)

Pour écrire et compiler du Java, il faut le JDK (Java Development Kit). Il contient le compilateur javac et la JVM java. Le JRE seul ne suffit pas. Installez une version LTS (support long terme) : JDK 21 ou plus récente. Nous recommandons la distribution gratuite Eclipse Temurin (site adoptium.net).

  1. Sur adoptium.net, téléchargez l'installeur .msi de Temurin 21 (x64).
  2. Pendant l'installation, activez les options « Add to PATH » et « Set JAVA_HOME variable ».
  3. Ou, en une commande dans PowerShell :
PS> winget install EclipseAdoptium.Temurin.21.JDK

Fermez puis rouvrez le terminal après l'installation pour que le PATH soit pris en compte.

  1. Téléchargez le .pkg de Temurin 21 sur adoptium.net (choisissez aarch64 pour les Mac Apple Silicon M1/M2/M3, x64 pour les Mac Intel) et lancez-le.
  2. Ou, si vous avez Homebrew :
$ brew install --cask temurin@21

Ubuntu / Debian :

$ sudo apt update
$ sudo apt install openjdk-21-jdk

Fedora : sudo dnf install java-21-openjdk-devel

Vérifiez l'installation dans un nouveau terminal. Les deux commandes doivent afficher un numéro de version (21 ou plus).

$ java -version
openjdk version "21.0.5" 2024-10-15 LTS
$ javac -version
javac 21.0.5
Problème ?Si javac n'est « pas reconnu » ou donne « command not found », le dossier bin du JDK n'est pas dans le PATH. Sous Windows, cherchez « Modifier les variables d'environnement système », puis ajoutez C:\Program Files\Eclipse Adoptium\jdk-21…\bin au Path. Rouvrez ensuite le terminal.

Choisir et configurer un IDE

Un IDE (environnement de développement intégré) colore le code, signale les erreurs pendant que vous tapez, complète les noms et lance le programme en un clic. Pour ce module, nous utilisons VS Code, mais les autres IDE conviennent aussi.

Configurer VS Code pour Java

  1. Installez VS Code depuis code.visualstudio.com.
  2. Ouvrez l'onglet Extensions (Ctrl+Shift+X, Cmd+Shift+X sur Mac) et installez Extension Pack for Java (éditeur : Microsoft). Il ajoute la coloration, l'autocomplétion, l'exécution et le débogueur.
  3. Fichier → Ouvrir le dossier… et choisissez votre dossier TP1. Travaillez toujours dans un dossier ouvert, pas sur un fichier isolé.
  4. Créez Bonjour.java. Après quelques secondes, des liens Run | Debug apparaissent au-dessus de main : cliquez sur Run. La sortie s'affiche dans le terminal intégré.
  5. Ouvrez le terminal intégré (Ctrl+`) : vous pouvez aussi y taper javac et java comme dans un terminal normal.
ConseilPendant les premières séances, compilez au moins une fois à la main avec javac et java dans le terminal. Le bouton Run fait exactement la même chose, mais il cache les deux étapes.

Premiers pas avec Git et GitHub

Git enregistre l'historique de votre code sur votre machine : chaque commit est une sauvegarde à laquelle vous pouvez revenir. GitHub héberge cet historique en ligne : votre travail est sauvegardé, accessible depuis n'importe quel PC de la salle, et vous construisez un portfolio.

1. Préparer les outils

  1. Créez un compte sur github.com. Choisissez un nom d'utilisateur professionnel (par ex. prenom-nom).
  2. Étudiant ? Demandez le GitHub Student Developer Pack (gratuit) : il donne accès à GitHub Copilot et à des outils professionnels.
  3. Installez Git : Windows winget install Git.Git (ou git-scm.com), macOS xcode-select --install, Linux sudo apt install git.
  4. Indiquez votre identité, une seule fois par machine (utilisez l'e-mail de votre compte GitHub) :
$ git --version
$ git config --global user.name "Sara Benali"
$ git config --global user.email "sara.benali@exemple.com"

2. Mettre le dossier TP1 sous Git

Dans le terminal, placez-vous dans votre dossier TP1. Créez d'abord un fichier .gitignore pour ne pas versionner les fichiers compilés :

$ cd TP1
$ echo "*.class" > .gitignore
$ git init
$ git add .
$ git commit -m "TP1 : premier programme Bonjour"
modifiervos fichiers .java
→
git addpréparer
→
git commitsauvegarder en local
→
git pushenvoyer sur GitHub

3. Publier sur GitHub

  1. Dans VS Code, avec le dossier TP1 ouvert, cliquez sur l'icône Source Control (Ctrl+Shift+G).
  2. Cliquez sur Publish to GitHub, connectez-vous dans le navigateur quand c'est demandé, puis choisissez private ou public.
  3. Ensuite, à chaque étape : écrivez un message, cliquez sur Commit, puis Sync Changes.
  1. Sur github.com : New repository, nom poo-tp1, sans cocher README ni .gitignore : votre dossier local a déjà son propre historique.
  2. Reliez votre dossier au dépôt en ligne et envoyez-le :
$ git branch -M main
$ git remote add origin https://github.com/votre-pseudo/poo-tp1.git
$ git push -u origin main

GitHub n'accepte plus le mot de passe du compte dans le terminal. Au premier push, une fenêtre de connexion s'ouvre (Git Credential Manager sous Windows et macOS). Sinon, utilisez un personal access token ou l'outil gh auth login.

HabitudeFaites un commit après chaque exercice réussi, avec un message clair : git commit -m "Ex 4 : calculatrice d'entiers". À la fin de la séance, faites git push. Ne publiez jamais de mot de passe ni de token dans votre code.
Avant de commencer

Comment Java fonctionne

Java ne s'exécute pas directement : le compilateur transforme votre fichier source en bytecode, que la machine virtuelle (JVM) exécute sur n'importe quel système. C'est le principe Write Once, Run Anywhere.

Bonjour.javacode source
→javac→
Bonjour.classbytecode
→java (JVM)→
WindowsLinuxmacOS
Règle 1Une classe public class Bonjour doit être enregistrée dans un fichier nommé exactement Bonjour.java, avec la même majuscule. Créez un dossier TP1 et mettez-y tous vos fichiers.

Bonjour Java

Bonjour Java
Je m'appelle Sara
Provoquez les erreurs. Faites ces changements un par un, recompilez, lisez le message, puis corrigez : (a) renommez la classe en bonjour ; (b) supprimez un ; ; (c) écrivez Main au lieu de main. Laquelle passe la compilation mais échoue à l'exécution ?
Indice

(a) et (b) sont refusées par javac. (c) compile, car Main est une méthode valide, mais la JVM ne trouve pas de point d'entrée main.

Calculatrice d'entiers

+ − * / %division entièrepriorité de +
  1. Dans Calcul.java, déclarez int a = 17; et int b = 5;.
  2. Affichez la somme, la différence, le produit, le quotient et le reste, exactement comme ci-dessous.
  3. Ajoutez une dernière ligne qui affiche le quotient réel 3.4.
17 + 5 = 22
17 - 5 = 12
17 * 5 = 85
17 / 5 = 3
17 % 5 = 2
17 / 5 (réel) = 3.4
Piège. Essayez System.out.println(a + " + " + b + " = " + a + b);. Pourquoi obtenez-vous 17 + 5 = 175 ?
Indice

+ s'évalue de gauche à droite : dès qu'une chaîne apparaît, la suite est concaténée. Mettez le calcul entre parenthèses. Pour le quotient réel, l'un des deux opérandes doit être réel : (double) a / b.

  2. Demandez dans cet ordre : le prénom, l'âge, la ville, puis la lettre du groupe.
  3. Affichez une phrase de synthèse.
Prénom : Sara
Âge : 20
Ville : Oran
Groupe : B
Bonjour Sara, tu as 20 ans, tu habites à Oran (groupe B).
Observez. Écrivez d'abord le programme sans précaution particulière. Que se passe-t-il au moment de saisir la ville ? Expliquez, puis corrigez.
Indice

nextInt() lit le nombre mais laisse le retour à la ligne (touche Entrée) dans le tampon. Le nextLine() suivant le lit tout de suite et renvoie une chaîne vide. Appelez nextLine() une fois de plus juste après nextInt() pour vider le tampon.

Il n'existe pas de nextChar() : lisez une ligne puis prenez son premier caractère avec charAt(0).

Indice

Testez d'abord le cas invalide avec || (« ou ») : note < 0 || note > 20. Ensuite, testez les mentions de la plus haute à la plus basse : chaque else if n'est atteint que si les conditions précédentes sont fausses.
